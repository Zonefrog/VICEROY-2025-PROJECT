Week 1: LLM-Content Benchmarking Datasets

Main Topic: Yelp Open Dataset for LLM-Content Research
- Sub-topics:
  1. Overview of the Yelp Open Dataset
  2. Types of data included in the dataset (e.g., user reviews, star ratings, metadata)
  3. Use cases and research applications of the Yelp Open Dataset
  4. Comparison with other benchmarking datasets (e.g., COCO, ImageNet)
- Brief explanation: This topic will explore the Yelp Open Dataset as a benchmarking dataset for LLM-content research, focusing on the types of data it contains and its relevance in various research applications.
- Learning objectives: Understand the structure and contents of the Yelp Open Dataset, identify its potential uses in LLM-content research, and compare it with other benchmarking datasets.
- Estimated number of slides: 15
- Lab activities: Analyzing and visualizing data from the Yelp Open Dataset, performing sentiment analysis on user reviews, and exploring correlations between metadata variables.
- Real-world applications: Sentiment analysis for business reviews, recommendation systems, and natural language processing research.

Week 2: LLM-Content Detection and Evading LLM Detectors

Main Topic: Evading LLM Detectors
- Sub-topics:
  1. Techniques for evading LLM detectors (e.g., adding irrelevant text, using synonyms)
  2. Adversarial attacks on LLM detectors
  3. Vulnerabilities exploited in LLM decision-making
  4. Strategies for enhancing LLM detection robustness
- Brief explanation: This topic will cover various techniques and strategies used to evade LLM detectors, including adversarial attacks and ways to improve detection robustness.
- Learning objectives: Recognize common evasion techniques, understand the concept of adversarial attacks, identify vulnerabilities in LLM decision-making, and explore methods for enhancing detection robustness.
- Estimated number of slides: 20
- Lab activities: Implementing adversarial attacks on a pre-trained language model, analyzing model outputs before and after attacks, and evaluating strategies to improve detection robustness.
- Real-world applications: Cybersecurity, content moderation, and improving the reliability of language model detection systems.
